# Parrot ANAFI 드론 제어 시스템 시작 가이드

## 구조
```
PWA (localhost:3000/status) 
  ↕ HTTP
Flask 브리지 (localhost:5000) 
  ↕ ARSDK
Olympe SDK 
  ↕ WiFi
ANAFI 드론 (192.168.42.1)
```

## 시작 순서

### 1. 드론 준비
1. Parrot ANAFI 드론 전원 켜기
2. PC/노트북을 드론 WiFi에 연결
   - WiFi 이름: ANAFI-XXXXXX
   - 비밀번호: 드론 배터리에 표시

### 2. Flask 브리지 서버 시작 (WSL2/Linux)
```bash
cd backend
python3 server.py
```

서버가 시작되면:
```
드론 컨트롤러 초기화 중...
드론 연결 시도 중... (IP: 192.168.42.1)
드론 연결 성공
Flask 브리지 서버 시작 중...
서버 주소: http://0.0.0.0:5000
```

### 3. Next.js PWA 시작
```bash
# 프로젝트 루트에서
npm run dev
```

### 4. 브라우저에서 테스트
```
http://localhost:3000/status
```

## 테스트 방법

1. **연결 상태 확인**
   - 페이지 로드 시 자동으로 드론 연결 상태 확인
   - 녹색: 연결됨 / 빨간색: 연결 안 됨

2. **이륙 테스트**
   - "✈️ 이륙" 버튼 클릭
   - 드론이 약 1.5m 높이로 이륙
   - 호버링 상태 유지

3. **착륙 테스트**
   - "🛬 착륙" 버튼 클릭
   - 드론이 천천히 착륙

## 주의사항

### 실내 테스트 시
- ✅ 충분한 조명 (어두우면 비전 센서 작동 안 함)
- ✅ 패턴이 있는 바닥 (단색 바닥은 위치 추적 어려움)
- ✅ 평평한 표면
- ✅ 장애물 없는 공간 (최소 2m x 2m)
- ✅ 천장 높이 충분 (최소 2.5m)

### 배터리
- 최소 20% 이상 필요
- 10% 미만이면 이륙 불가

### 문제 해결
1. **드론 연결 실패**
   - 드론 WiFi에 연결되어 있는지 확인
   - IP 주소가 192.168.42.1인지 확인
   - 드론 재부팅

2. **이륙 안 됨**
   - FreeFlight 앱으로 드론 상태 확인
   - 프로펠러 정상 장착 확인
   - 평평한 바닥에 놓기
   - 실내: 조명 밝게, 패턴 있는 바닥

3. **서버 연결 안 됨**
   - Flask 서버가 실행 중인지 확인
   - CORS 설정 확인
   - 방화벽 확인
